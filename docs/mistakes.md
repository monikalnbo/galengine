# galengine 错题本（本次从零重构）

> 需求书 §5 的 8 条是上一实现的血泪；本册是本次重写自己踩的坑，**全类别记录**。
> 每条：症状 → 根因 → 修法 → 通用教训。动相关代码前先翻对应类目。

## A. 引擎代码错题

**A1 表达式右结合折叠算错**（`10-4-1=7`、`f.a - -1` 报空表达式）
根因：取最右分割符做右结合，连续同优先级运算符语义错；二元减号后跟一元减号时中间段为空。
修法：重写为左结合折叠 + 折叠前过滤空段（空段前的连续 `+/-` 视为一元符号并入操作数）。
教训：表达式求值器必须有「左结合+一元号」的组合用例，光测单运算符测不出。

**A2 缺名变量破坏 `??` 语义**（`f.nothing ?? f.a` 得到字符串 `"f.nothing"`）
根因：atom 把未命中的带点变量当「裸词字符串常量」返回，`??` 看到非空串不取右值。
修法：带点未命中 → 返回空串（blank 语义）；无点裸词才当字符串常量。
教训：变量名和字符串常量共享一个词法空间时，必须明确「未定义变量」的求值规则。

**A3 字符串参与关系运算静默转数字**（`sf.name > 1` 不报错）
修法：任一侧是 Str 且运算符是 `>` `<` `>=` `<=` → 中文报错，只允许 `==`/`!=`。
教训：宽松隐式转换会掩盖剧本作者的类型笔误，宁可严格。

**A4 global.json 把 f.\* 也序列化**（违规格：f 随档、sf 全局）
根因：直接序列化整个 Vars 结构体。
修法：单独 GlobalFile{sf} 落盘/读取。
教训：持久化格式以「规格字段」为单位定义结构体，不要顺手存整个内存对象。

**A5 meta_fake_save 按空白拆参**（`meta_fake_save 7月7日|23:59|图` 报用法错误）
根因：`日期|时间|图` 是一个含管道的 token，不是三个空白分隔参数。
修法：该指令按 `|` 切分。input 指令同理。
教训：写解析器时拿真实剧本样例对拍，别按想象中的参数形态写。

**A6 auto_step 仪式臂每次重置 fade=0**（三击后永不白满、永不真删档）
根因：确认推进时重建整个 Overlay 状态，把正在上升的 fade 归零。
修法：推进只改 step，fade/done 原样保留。
教训：重建状态机值时逐字段过一遍「哪些在演化」；自动驱动路径也要覆盖演出时序。

**A7 Esc 在标题画面清掉 overlay → 未开局黑屏死锁**
根因：Esc 统一「overlay→None」，但标题态没有游戏在跑，None 后无任何可交互内容。
修法：标题态 Esc 不动作（必须选菜单项进入）。
教训：全局快捷键处理前先枚举「当前态下这个动作让引擎进入什么态」。

**A8 退出游戏用 process::exit**（sf.* 不落盘）
根因：菜单激活函数返回值类型装不下「退出」信号，图省事直接 exit。
修法：退出作为 bool 信号层层上抛到主循环，走正常收尾（save_global）。
教训：任何绕过主循环收尾路径的 exit 都是存档丢失事故预定。

**A9 BGM 不随存档**（读档后音乐错位）
根因：把 bgm 当纯音频指令，没纳入场景状态。
修法：interp 记 cur_bgm → 存档加 bgm 字段（serde default 兼容旧档）→ 读档有则重播、无则停。
教训：「玩家听到的」和「玩家看到的」都是场景状态，存档快照要一起带走。

**A10 WaitChoice 漏 prompt 字段**（选项提示语不显示）
根因：状态枚举只装了 items，渲染层拿不到提示。
修法：enum 加 prompt 并在渲染时展示。
教训：等待态枚举的字段=UI 需要的全部信息，定义前先写渲染草稿。

**A11 杂项语法/借用**
- `self.chars.map()` 移动整个数组（array::map 取所有权）→ `[0,1,2].map(|i| self.chars[i]..)` 索引访问
- 后台线程 `send(path)` 后再 `decode(&path)` → 先算后 move
- 借用 overlay 判分支时又给 overlay 赋值 → 先算局部再落盘
- 全角括号 `format！（`、sed 多行不匹配静默失败 → 编辑后必 build 验证

**A12 按钮文字误用全屏居中**（名字输入页确认按钮文字与预设名重叠）
根因：按钮绘制的文字坐标用了全屏居中算法，按钮矩形只在背景绘制时使用。
修法：文字在按钮矩形内居中；补几何单测（断言文字中心=按钮中心）。
教训：部件的「背景」和「文字」必须共享同一几何源；居中算法参数化后用单测锚住。

## B. Rust-sdl2 API 错题

**B1 mixer 类型名与 C 名不同**：`MixMusic`/`Mix_Chunk` 不存在 → `Music`/`Chunk`；写封装前先 grep 本机 crate 源码签名，别凭 C API 记忆。
**B2 open_audio 参数**：第二参是 `AudioFormat` 常量（`AUDIO_S16LSB`），不是频率常量；返回 `Result` 不是 bool；`allocate_channels` 返回 i32。
**B3 run_tests 循环变量没进引擎**：`for s in ...` 但命令行没传 `ES_SCRIPT=$s`，三循环跑同一剧本还全绿——假阳性。修法：脚本里显式传参；教训：**回归脚本的每个循环变量必须出现在被测命令里**。
**B4 .gitignore 漏 /savedata**：meta/global 测试产物差点入库。
**B5 纹理通道 R↔A 互换**（半透明立绘泛红、切场景背景偏红）
根因：image crate 解码出的 RGBA 内存序在小端机器上与 SDL `PixelFormatEnum::RGBA8888` 的字节序定义相反，红/alpha 互换。
修法：自建纹理改用 `ABGR8888`（与 image 输出的小端内存序一致）。
教训：SDL 像素格式名描述的是「字节序布局」而非「内存序」；自建纹理通道序先用纯红/纯绿样图验证，肉眼泛红=通道错位的典型症状。

**B6 image::open 只按扩展名选解码器**（bg_port.jpg 实为 PNG 字节 → JPEG 解码器拒绝）
根因：image 0.25 的 `open()` = `ImageReader::open()?.decode()`，不含 `with_guessed_format()`；旧 SDL2_image 时代按魔数嗅探，素材扩展名错了也能跑。
修法：显式 `.with_guessed_format()` 魔数嗅探；保留一张「披着 jpg 外衣的 PNG」在回归数据里钉住该行为。
教训：更换图像库时对齐「容忍度」而不是只对齐功能——旧引擎能跑的野数据，新引擎也必须能跑。

## C. 验收与像素测试错题

**C1 单帧截图猜时序，三次误拍**：拍到标题屏（忘了无 autoclick 停在标题）/ 旁白行（名牌只在 name 行）/ reach alpha≈0（启动延迟吃掉淡入时间）。
修法：**单进程 ffmpeg `-framerate` 连拍整段 + 逐帧扫描目标特征**，不再猜时刻。
教训：启动耗时是变量（首帧 0.5~2s 浮动），任何「第 N 秒该出现 X」的假设都不可靠。

**C2 像素断言忘了 letterbox 偏移**：窗口 1280×800 里游戏区在 y+40，采样区全部错位。
教训：断言坐标先画一遍「窗口/游戏区/采样区」三者关系再写。

**C3 断言过严产生假阴性**：对话框要求 g≥r 精确成立，实际混色差 2 就 FAIL；有效断言是「性质」（够暗、够蓝）而非「精确序」。

**C4 reach 越界验证无黑边可越**：窗口默认 1280×720=游戏比例，letterbox 无 bar。
修法：xdotool `windowsize` 把窗口拉成 1280×800 再验。
教训：验证「打破边界的功能」前，先确认边界存在。

**C5 软件渲染首帧慢，重踩血泪 #3**：拍标题背景 sleep 1.0s 全黑，2.2s 才有帧；随后 2.2s 又撞上 autoclick 已开局。修法：autoclick 拉长 + sleep≥2s。
教训：需求书踩坑条目在写测试前要重读一遍，自己写的就是要拿来约束自己的。

## D. 测试自身错题

**D1 手写旧档 JSON `thumb:""`**：Vec<u8> 期望数组 → 解析 None 被吞。修法：`.ok()` 吞错的 load 在测试里要 unwrap_err 打出真实错误。
**D2 dummy 环境没人调 apply_pending**：tw 永远是空页=「已读完」，两次 click 直接冲过 end。
教训：脱离主循环单测解释器时，打字机的「文本装载」步骤必须手动补，否则推进语义完全不同。
**D3 测试间共享进程 env**（ES_DATA_DIR set_var）存在并行竞态隐患；SDL 全局初始化型测试保持每进程一个。

## E. 工程流程错题

**E1 edit 工具 oldText 块圈太大，一次替换顺带删掉了 do_save 整个函数**。
教训：oldText 只圈要改的最小片段；替换含函数边界的块后立刻 grep 确认函数还在。
**E2 `grep -c` 无匹配 exit 1 截断 `&&` 链**，后续命令静默不跑。教训：计数 grep 用 `|| true` 包。
**E3 占位模块先建后填**（M2 前的 stub 文件）：浪费一次全量编译周期；正确顺序是「依赖方最后写」。
**E4 Overlay::Rest 死变体**：rest 状态实际存在 sys.rest，枚举里又建了一个从没用上。教训：同一状态只有一个真相源；enum 变体建了没引用要当 bug 看。

## 防复发规则（从上提炼）

1. **回归脚本循环变量必须出现在被测命令里**（B3）
2. **视觉验收一律连拍逐帧扫描，不猜时刻**（C1/C5）
3. **像素断言写性质不写精确值，坐标先算 letterbox 偏移**（C2/C3）
4. **`.ok()` 吞错的测试路径必须 unwrap_err 可见**（D1）
5. **解释器单测手动补 apply_pending**（D2）
6. **edit 圈最小块，函数边界替换后 grep 验存**（E1）
7. **任何 exit 必须走主循环收尾**（A8）
8. **自动驱动要覆盖演出时序（fade/倒计时），不只是点击推进**（A6）
9. **自建纹理先用纯色样图验证通道序，泛红=R↔A 互换**（B5）
10. **换图像库必须对齐容忍度：魔数嗅探不能丢，野数据进回归**（B6）
